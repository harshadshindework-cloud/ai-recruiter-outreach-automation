# Workflow

## Day 01
Read pending recruiter rows → send application → capture Thread ID → mark Sent → calculate business-day follow-ups.

## Day 02/03/04
Find due Pending rows → load Thread ID → reply inside existing Gmail conversation → mark follow-up Sent → record actual send date.

## Failure principle
A tracking/metadata failure must not automatically trigger a second email. Distinguish a genuine send failure from a post-send tracking failure to prevent duplicate recruiter outreach.
